Opus Header Component Demo

Chinese Header (Home Page)

This shows the header for the Chinese home page with "首頁" highlighted.

<opus-header language="zh" current-page="home"></opus-header>

English Header (Events Page)

This shows the header for the English events page with "Events" highlighted.

<opus-header language="en" current-page="events"></opus-header>

Supported Page Types

  • current-page="home" - Highlights home link
  • current-page="events" - Highlights events link
  • current-page="team" - For team pages (when uncommented)
  • current-page="donors" - For donor pages
  • current-page="partners" - For partner pages
  • current-page="friends" - For membership pages

Language Support

  • language="zh" - Chinese text and links
  • language="en" - English text and links

The component automatically adjusts logo paths, menu text, and link destinations based on the language.

Integration Instructions

  1. Include the header component script: <script src="components/header.js"></script>
  2. Replace your existing nav section with: <opus-header language="[zh|en]" current-page="[page-type]"></opus-header>
  3. The component handles all styling and interactions automatically

Benefits

  • ✅ Consistent navigation across all pages
  • ✅ Easy maintenance - update in one place
  • ✅ Automatic language switching
  • ✅ Responsive design built-in
  • ✅ Shadow DOM isolation prevents style conflicts
  • ✅ Easy to extend with new features
