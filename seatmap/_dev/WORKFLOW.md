# 座位圖工具 工作說明

## 目錄結構

```
website/seatmap/
├── _dev/                          ← 開發檔案（不部署、不進 git）
│   ├── WORKFLOW.md                ← 本文件
│   ├── nch/
│   │   ├── source.html            ← OPENTIX 原始 SVG（勿覆蓋）
│   │   ├── 國家音樂廳座位圖...xlsx  ← 場館座位圖 Excel
│   │   ├── generate.py            ← 產生 nch/nch.html（觀眾版）
│   │   ├── generate-editor.py     ← 產生 nch/editor-nch.html（定價工具）
│   │   ├── apply-pricing.py       ← 用 CSV 更新 nch/nch.html 顏色
│   │   └── update-excel.py        ← 用 CSV 在 Excel 新增定價工作表
│   ├── nrh/  (同上結構，四個腳本全備)
│   ├── tct/  (同上結構，四個腳本全備)
│   └── wwy/  (同上結構，四個腳本全備)
├── nch/
│   ├── nch.html                   ← 部署：觀眾瀏覽版
│   └── editor-nch.html            ← 部署：助理定價工具
├── nrh/ tct/ wwy/  (同上)
```

**部署網址：**
- 觀眾瀏覽：`https://opusformosa.org/seatmap/{venue}/{venue}.html`
- 定價工具：`https://opusformosa.org/seatmap/{venue}/editor-{venue}.html`

## 每次新音樂會的標準流程

### 步驟 1 — 更新音樂會資訊（每次必做）

打開各場館的 `_dev/{venue}/generate.py`，修改頂部的 `CONCERT` 區塊：

```python
CONCERT = {
    'name':  '2027 XX 音樂會',   # ← 只在 HTML <title> 中顯示，可不改
    'venue': '國家兩廳院音樂廳',
}
```

### 步驟 2 — 重新產生 HTML

```bash
cd website/seatmap/_dev/nch
python3 generate.py           # 產生 nch/nch.html（觀眾版，無定價顏色）
python3 generate-editor.py    # 產生 nch/editor-nch.html（定價工具）
```

### 步驟 3 — 助理填寫定價

1. 把 `editor-{venue}.html` 的網址傳給助理：  
   `https://opusformosa.org/seatmap/{venue}/editor-{venue}.html`
2. 助理在網頁上框選座位 → 輸入票價 → 套用
3. 助理點「下載 CSV」，得到 `{VENUE}定價-YYYY-MM-DD.csv`
4. 助理把 CSV 傳回給你

### 步驟 4 — 用 CSV 更新觀眾版座位圖

```bash
cd website/seatmap/_dev/nch
python3 apply-pricing.py NCH定價-2026-04-03.csv
# → 更新 nch/nch.html，座位依實際票價上色
```

### 步驟 5 — 用 CSV 更新 Excel，回傳票務系統

```bash
cd website/seatmap/_dev/nch
python3 update-excel.py NCH定價-2026-04-03.csv
# → 在 Excel 新增「定價紀錄」與「票價摘要」工作表，輸出新檔（原檔不覆蓋）
# → 把輸出的 xlsx 傳給票務系統
```

### 步驟 6 — 部署

```bash
cd website
./deploy.sh
```

## 定價工具（editor）操作說明

| 操作 | 方式 |
|------|------|
| 選單一座位 | 單擊 |
| 加入/取消選取 | Shift 或 Ctrl + 點擊 |
| 框選一區域 | 滑鼠拖拉（從空白處開始） |
| 選取同票價所有席 | 點右側圖例中的票價 |
| 設定票價 | 輸入數字 → Enter 或「套用」 |
| 清除選取 | 按「清除選取」 |
| 重設全部 | 按「重設全部定價」（有確認提示） |
| 下載 CSV | 按「下載 CSV」 |

**注意事項：**
- 定價進度自動存在瀏覽器 localStorage，重新整理不遺失
- 不可販售席（工作席、錄影席、樂池席）無法選取，不會出現在 CSV 的 price 欄
- 匯入 CSV 時會驗證場地名稱，不同場地的 CSV 無法互用

## CSV 格式說明

```
# venue=國家兩廳院音樂廳
section,row,seat,type,price
2樓,14,1,regular,2500
2樓輪椅席,25,33,wheelchair,1200
2樓,17,38,staff,
```

| 欄位 | 說明 |
|------|------|
| `section` | 區域（對應 SVG 中的 section 名稱） |
| `row` | 排數（數字或字母，如 `14`、`2L`、`VA`） |
| `seat` | 座位號碼 |
| `type` | 座位類型（見下表） |
| `price` | 票價（元，純數字；不販售席留空） |

**type 值一覽（不同場館支援的類型有所不同）：**

| type | 中文 | 可定價 | 場館 |
|------|------|--------|------|
| `regular` | 一般席 | ✓ | 全部 |
| `staff` | 工作席 | ✗ | 全部 |
| `recording` | 錄影席 | ✗ | TCT |
| `recording_view_affected` | 錄影視線受影響席 | ✗ | TCT |
| `pit` | 樂池席 | ✗ | TCT |
| `vip_box` | 貴賓包廂 | ✓ | NCH |
| `wheelchair` | 輪椅席 | ✓ | 全部 |
| `companion` | 輪椅陪同席 | ✓ | 全部 |
| `accessible` | 多元友善席 | ✓ | NCH、NRH、TCT |
| `accessible_companion` | 多元友善陪同席 | ✓ | NCH、NRH、TCT |
| `obstructed` | 視線不良席 | ✓ | 全部 |
| `organ_obstructed` | 管風琴視線不良席 | ✓ | NCH |
| `uncomfortable_obstructed` | 座位不適・管風琴視線不良席 | ✓ | NCH |
| `photography` | 攝影保留席 | ✗ | NRH |
| `console` | 控台區 | ✓ | WWY |
| `chorus` | 合唱席 | ✗ | WWY |
| `reserved` | 保留席 | ✗ | WWY |

## 修改場館特殊席配置

特殊席（如輪椅席位置）由各場館固定，通常不需修改。若場館改建，修改：
- `_dev/{venue}/generate-editor.py` 頂部的 `SECTION_TYPES` 和 `SEAT_TYPES`
- 改完後重新執行 `python3 generate-editor.py`
